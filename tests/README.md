# Tests

Plain Lua 5.1 tests for the core (including the error collector) (`run.lua`) the item module (`items.lua`) the gold journal (`ledger.lua`, `ledger2.lua` for auction house sales, purchases, deposits and the vendor check, which reuses the stubbed boot of `ledger.lua`) the loot memory (`loot.lua`) the mail overview (`mail.lua`) the whisper windows (`whisper.lua`: filing by partner, Battle.net keys, secret values during chat lockdown that are only queued by line ID and resolved afterwards, window and combat, sending and splitting, sound, history caps and option, command) the waypoints (`way.lua`) the world map helpers (`map.lua`: level line and colours, continent hover label, coordinates and their update timing, exploration stored and merged per map, overlays drawn only where this character has not explored, tile sizes, the 400-map cap, forget, options and a world map that loads later) the minimap button collector (`buttons.lua`) the butler (`butler.lua`: selling junk one item per tick with keep list, Shift, cap, stop on close and combat, repair order and guild funds, resurrection, duel throttle, error frame, missing functions and the keep command) the SempreUI fonts (`fonts.lua`: roles, option, language guard, fallback, game font replacement and `/sempre schrift`; the mail panel roles are checked in `mail.lua`, the greyed option in `settings.lua`) the rare detection (`rares.lua`: rare and rare elite from nameplate, target and mouseover, ignored normal, elite, dead, player and secret units, GUID and NPC throttles, chat line, sound and banner with their options, secure click action out of combat and the plain banner with hint in combat, right and Shift + right click, the seen list with merged places and caps, commands and the nameplate hint) the "what's new" window (`news.lua`: when it opens, first install, option, combat, command, language, entries newest first and the scan that allows only the GitHub issues link in the game texts) the compatibility check (`compat.lua`: detection of EllesmereUI and Naowh Forever by folder name and title, the rule table, when the window opens, the wait for the news window and combat, the stored answer, switching modules and options, reload button, command and languages) and the settings window with the option interface (`settings.lua`, all run by `run.lua`) with a stubbed WoW API. They are not part of
the addon package (`tests` is in the `.pkgmeta` ignore list).

Run from the repo root:

    lua5.1 tests/run.lua

It prints the number of checks and exits non-zero on any failure. CI runs it
in `.github/workflows/lint.yml`.
