# Contributing

Thanks for helping! A few rules keep SempreUI light and clean:

- By contributing you agree that your contribution is licensed under the
  GPLv3, like the rest of the project.
- Do not paste code from other addons, whatever their license. Reading them
  to understand a problem is fine; the solution here is written fresh.
- Every module stays LoadOnDemand and states its memory budget in its `.toc`
  (`## X-Sempre-Budget-KB`).
- Code must pass `luacheck .` without warnings.
- In combat, only display. No decisions based on secret values.

Feedback and ideas are welcome as GitHub issues.
